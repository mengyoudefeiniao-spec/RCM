# 腾讯云本地人脸演示

演示使用腾讯云人脸识别 DetectFace（IAI，广州地域）检测两张图片中是否恰有一张人脸；使用人脸核身 GetActionSequence 和 LivenessCompare（FaceID）获取动作顺序、检测动作视频并与参考照片比对，返回最佳截图。人脸核身与人脸识别是两个服务，须分别开通并授权。相关 API：https://cloud.tencent.com/document/api/867/45023 、https://cloud.tencent.com/document/api/1007/31819 。

1. 在腾讯云控制台开通人脸识别和人脸核身服务，确认账户可调用 DetectFace、GetActionSequence 和 LivenessCompare，并确认服务资质、地区、免费额度和计费。超过免费额度可能转为按量计费。
2. 创建权限受限的 CAM 密钥。长期密钥只需 SecretId 和 SecretKey；如果使用临时密钥，还需 Token。不要把密钥提交 Git、写入环境变量文件或发到聊天。建议使用短期有效、权限最小的临时密钥并及时撤销。
3. 本机运行 `npm run dev`，在同一机器用 `http://localhost:3000` 打开。输入密钥，选择参考照片，开启摄像头，录制并按顺序完成两个动作，发送检测，确认前可下载返回截图。当前浏览器须支持 MediaRecorder 录制 H.264 MP4。IAM/华为云 Token 不再使用。

页面输入的密钥、照片和视频会通过本机 Vite 开发服务器传递，由本机服务器签名后经 HTTPS 发往腾讯云；密钥仅存于当前弹窗内，关闭时清除，不会保存到项目文件，但浏览器扩展或本机其他有权限的软件仍可能读取。接口仅供 localhost 本机演示；不要公开开发服务器、使用管理员密钥或用于生产。静态构建、预览和 Android 打包不包含本地代理。

参考照片目前手动选择，不是可信芯片照片；比对结果仅用于 Mock 演示，不构成正式身份认证。没有连接真实账户的联调时，不能保证云端可用；腾讯云服务可能按调用收费，请预先在控制台确认。
