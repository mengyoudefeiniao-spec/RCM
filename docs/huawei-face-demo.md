# 华为云人脸演示配置

本功能仅支持本地 Vite 开发服务器（`npm run dev`），由其固定转发到华北-北京四 FRS 服务；不适用于静态发布、`vite preview` 或正式服务。请使用本机 localhost 访问，避免在局域网中传输 Token 和生物信息。没有将 AK/SK 或 Token 配置在代码中。

1. 登录华为云中国站，在华北-北京四开通人脸检测、人脸比对和动作活体检测三个 FRS 子服务。以账号当前控制台提示为准，确认权限、开通条件、地区与计费。
2. 在“我的凭证”获取华北-北京四的项目 ID。按照 https://support.huaweicloud.com/qs-face/face_09_0003.html 获取该项目的 IAM 用户 Token（X-Subject-Token）。建议使用只授予所需 FRS 权限的临时 IAM 用户 Token，不要把密码、AK/SK 或 Token 提交到 Git、聊天或配置文件。
3. 在项目中运行 `npm run dev` 并通过本机 `http://localhost:3000` 打开。在人脸核验弹窗中填写项目 ID 与 Token；Token 在关闭弹窗时清除。
4. 选择已取得同意的 JPG/PNG 参考照片，打开摄像头，录制 5 秒并完成提示的一个动作。点击发送后，前端通过本机 Vite 开发服务器把视频及图片发送到华为云；返回的截图可手动下载。界面在检测通过后才允许在 Mock 演示流程中确认。

每次调用动作活体检测可能收费；后续最多另调用两次人脸检测和一次人脸比对。华为云计费说明称动作活体检测不包含在每月免费调用额度中，实际价格、余额、免费范围及计费规则请在控制台确认。文档：https://support.huaweicloud.com/productdesc-face/face_01_0016.html

动作检测只检测指定动作是否发生，不验证人物真实性。人脸相似度阈值 0.93 仅按文档建议用于演示，未针对实际人群校准。参考照片由使用者选择，不代表真实 OCR 或芯片照片。图片、视频、令牌和结果不应被视为可信的正式身份核验凭证。实际部署前仍需正式的用户授权、服务端认证和审计、安全存储、活体防伪和可信芯片验证。
