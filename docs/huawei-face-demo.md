# 华为云人脸演示配置

> **状态：已废弃（待替代）**。本文仅为早期云端演示配置，不作为实现基线。活体检测与人脸 1:1 比对以《技术验证》离线方案（MediaPipe 挑战式活体 + ArcFace，v2.3）为准；替代方案落地后本文删除或归档。评估结论见《5-技术验证清单.md》TV-07。

本功能仅支持本地 Vite 开发服务器（`npm run dev`），由其固定转发到华北-北京四 FRS 服务；不适用于静态发布、`vite preview` 或正式服务。请使用本机 localhost 访问，避免在局域网中传输 Token 和生物信息。没有将 AK/SK 或 Token 配置在代码中。本地可选的 IAM 密码以明文保存在 Git 忽略的 `.env.local` 中，请仅在受信任设备上使用。

1. 登录华为云中国站，在华北-北京四开通人脸检测、人脸比对和动作活体检测三个 FRS 子服务。以账号当前控制台提示为准，确认权限、开通条件、地区与计费。
2. 创建拥有所需 FRS 权限、已开启编程访问的 IAM 用户。华为账号升级后不能直接使用主账号密码取得 Token；请使用该 IAM 用户。参见 https://support.huaweicloud.com/api-iam/iam_30_0001.html 。
3. 若要选择照片时自动获取 Token，在本地 Git 忽略的 `.env.local` 中设置 `HUAWEI_IAM_ACCOUNT`、`HUAWEI_IAM_USERNAME`、`HUAWEI_IAM_PASSWORD`（不要加 `VITE_` 前缀）。这三个值仅供本机开发服务读取，不要提交或分享该文件。启动或修改配置后重新运行 `npm run dev`，通过本机 `http://localhost:3000` 打开。选择参考照片时将自动获取区域项目 ID 和 Token；也可以在弹窗中手动输入 IAM 信息获取。自动方式的密码保存在本机文件中，Token 在关闭弹窗时清除。只允许本机回环地址使用 IAM 转发。
4. 选择已取得同意的 JPG/PNG 参考照片，打开摄像头，录制 5 秒并完成提示的一个动作。点击发送后，前端通过本机 Vite 开发服务器把视频及图片发送到华为云；返回的截图可手动下载。界面在检测通过后才允许在 Mock 演示流程中确认。

每次调用动作活体检测可能收费；后续最多另调用两次人脸检测和一次人脸比对。华为云计费说明称动作活体检测不包含在每月免费调用额度中，实际价格、余额、免费范围及计费规则请在控制台确认。文档：https://support.huaweicloud.com/productdesc-face/face_01_0016.html

动作检测只检测指定动作是否发生，不验证人物真实性。人脸相似度阈值 0.93 仅按文档建议用于演示，未针对实际人群校准。参考照片由使用者选择，不代表真实 OCR 或芯片照片。图片、视频、令牌和结果不应被视为可信的正式身份核验凭证。实际部署前仍需正式的用户授权、服务端认证和审计、安全存储、活体防伪和可信芯片验证。
